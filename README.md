# Intro to Geometry — Practice

Weekly practice for AIC Hybrid’s Intro to Geometry course.

**Live site:** https://sethjlevyhub.github.io/geometry-practice/

Pick a week, sign in with the name and password your teacher gave you, and submit when you are done. Week 20 is a timed final exam (40 minutes) and submits automatically when time is up.

Scoring happens on the teacher’s Google account. This repository does not contain answer keys, a student roster, or passwords. Please do not add any of those files here.
